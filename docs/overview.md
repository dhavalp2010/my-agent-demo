## Contribution Guidelines

We welcome contributions! Please follow these steps:

1. **Fork the repository** and clone your fork.
2. **Create a new branch** for your feature or bug fix:
   ```bash
   git checkout -b feature/your-feature-name
   ```
3. **Make your changes** and ensure that the code passes existing tests.
4. **Write or update documentation** as needed.
5. **Submit a pull request** targeting the `main` branch. Include a clear description of the changes and reference any related issues.

### Code Style
- Follow PEP 8 guidelines.
- Run `flake8` and `black` before committing.

### Testing
- Add unit tests for new functionality.
- Run the test suite with:
  ```bash
  pytest
  ```

For any questions, feel free to open an issue or contact the maintainers.
